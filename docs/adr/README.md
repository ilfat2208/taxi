выбранный вариант, альтернативы и последствия. Формат — сжатый ADR.

## Как добавить решение

1. скопировать шаблон из любого ADR;
2. описать контекст (что заставило выбирать), варианты и последствия;
3. добавить строку в таблицу выше;
4. не редактировать старые ADR — вместо этого писать новый со статусом
   «заменяет 000X».
