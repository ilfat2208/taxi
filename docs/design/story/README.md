# Вертикальная история ORTA (видео для сторис)

Здесь собирается ролик 1080×1920 (9:16) про проект ORTA: 38 секунд, 30 к/с,
восемь сцен. Основа — сам дизайн-борд: экраны телефонов не нарисованы заново, а
взяты из `docs/design/orta-screens.html` вместе с его дизайн-токенами и иконками.

| Файл | Что это |
|---|---|
| `extract.mjs` | Достаёт из борда стили, библиотеку inline-SVG и разметку нужных экранов в `assets/` |
| `timing.mjs` | Тайминги сцен — единственный источник правды для показа и рендера |
| `story.html` | Кадр 1080×1920 и оформление: палитра ORTA Blue из борда |
| `story.js` | Раскадровка: сцены, кривые движения, сборка кадра по номеру |
| `render.mjs` | Рендер кадров в PNG через Playwright |
| `make-audio.mjs` | Синтез фоновой подложки (`audio/orta-story.wav`) без внешних сэмплов |
| `encode.ps1` | Сборка MP4/WebM из кадров через ffmpeg |
| `geometry.mjs` | Отчёт по раскладке кадра числами — проверка, что ничего не наезжает и не вылезает |

## Как собрать

Playwright установлен в `web/`, поэтому команды запускаются оттуда.

```powershell
cd C:\taxi\web

# 1. Забрать экраны, стили и иконки из борда (нужно после правок борда)
node ..\docs\design\story\extract.mjs

# 2. Отрисовать кадры (~1140 PNG, примерно 3–4 минуты на этой машине)
node ..\docs\design\story\render.mjs

# 3. Посчитать подложку и собрать видео
cd C:\taxi\docs\design\story
node make-audio.mjs
pwsh -File encode.ps1
```

Готовые файлы кладутся в `docs/media/`:

- `orta-story-9x16.mp4` — вертикаль 1080×1920, H.264 + AAC, основной формат для сторис;
- `orta-story-9x16.webm` — тот же ролик в VP9/Opus;
- `orta-story-1x1.mp4` — квадрат 1080×1080 (кадрируется центр вертикали) для ленты.

## Проверка без полного прогона

```powershell
cd C:\taxi\web

# только выбранные кадры — быстрая вычитка сцен
$env:CHECKPOINTS="60,144,400,550,768,888,1000,1104"
$env:OUT="C:\taxi\docs\design\story\_check"
node ..\docs\design\story\render.mjs

# раскладка кадра числами: рамки, отступы, выход за пределы кадра
node ..\docs\design\story\geometry.mjs 400,550,1000
```

`render.mjs` понимает `FROM`, `END`, `OUT`, `FORMAT` (`png` или `jpeg`) и
`CHECKPOINTS`. Полный прогон всегда отрисовывает кадры заново и очищает каталог.

## Почему кадры считаются, а не записываются

`story.js` не проигрывает анимацию по времени: для каждого номера кадра он
расставляет элементы. Рендер идёт с выключенными CSS-переходами и снимает кадр
через CDP после двойного `requestAnimationFrame`. Поэтому результат не зависит от
нагрузки на машину, повторяем кадр в кадр и любой отрезок можно перерисовать
отдельно.

## Звук

`make-audio.mjs` синтезирует подложку сам: ля-минор, аккорды Am–F–C–G, мягкая
атака и спад без щелчков, общая длительность берётся из `timing.mjs`. Внешних
сэмплов и лицензионных ограничений нет. Чтобы собрать видео без звука, удалите
`audio/orta-story.wav` перед запуском `encode.ps1`.

## Правки

- **Текст и подписи** — объект `LABELS` в `story.js`.
- **Порядок и длительность сцен** — `SCENE_SPANS` в `timing.mjs` и вызовы `scene()`.
- **Какие экраны попадают в ролик** — список `WANTED` в `extract.mjs`, затем
  повторный `extract.mjs`.
- **Цвета** — только токены борда (`--brand-*`, `--ink-*`) в `story.html`; новых
  цветов не заводится.

`assets/` целиком генерируется `extract.mjs` — править эти файлы вручную не нужно.
